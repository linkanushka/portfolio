# Anushka Singh — Portfolio

Personal portfolio website showcasing my projects and skills, built with HTML, CSS, and JavaScript.

🌐 **Live Demo**: [https://netportfoli.netlify.app/](https://netportfoli.netlify.app/)

## Tech Stack

- **HTML** - 45.2%
- **CSS** - 51.1% 
- **JavaScript** - 3.7%

## Features

- Responsive and modern design
- Smooth scroll animations
- Interactive elements
- Mobile-friendly layout
- Fast-loading performance

## Folder Structure

```
portfolio/
├── index.html          # Main HTML file
├── README.md           # This file
└── assets/
    ├── css/
    │   └── style.css   # All styles
    ├── js/
    │   └── main.js     # Scroll, animations, interactions
    └── images/         # Portfolio images
```

## How to Use

Just open `index.html` in your browser — no build step needed.

### Local Development

1. Clone the repository
2. Navigate to the project folder
3. Open `index.html` in your browser

## How to Customize

- Update your email in `index.html` (search: `your.email@example.com`)
- Add a profile photo to `assets/images/` and reference it in `index.html`
- Edit text content directly in `index.html`
- Tweak colors/fonts in `assets/css/style.css` (CSS variables at the top)
- Modify animations and interactions in `assets/js/main.js`

## Deployment

This portfolio is deployed on **Netlify** at [https://netportfoli.netlify.app/](https://netportfoli.netlify.app/)

To deploy your own:
1. Push your code to GitHub
2. Connect your repository to Netlify
3. Netlify will automatically build and deploy your site
